# 上市公司与股票深度投资研究指南 (Investment Research)

当接收到「分析某家上市公司」或股票投资研究任务时，请遵循以下专业券商投研框架进行深度剖析：

## 1. 核心投资逻辑与商业模式
- **主营业务与产品线**：核心收入与利润来源是什么？
- **护城河与竞争壁垒**：在行业格局中拥有何种定价权、品牌、技术或渠道优势？

## 2. 财务中枢与盈利质量
- **成长能力**：营收同比与归母净利润同比增速趋势；
- **盈利韧性**：ROE（净资产收益率）、毛利率与净利率波动区间；
- **资产结构**：资产负债率、现金流充裕度与应收账款周转。

## 3. 技术面与资金博弈
- **均线与趋势形态**：短期（MA5/10）与中期（MA20/60）多空排列结构；
- **量价配合**：是否存在放量突破、量价背离或缩量回踩；
- **关键博弈点位**：近期的核心支撑位、上行阻力位与纪律防守位。

## 4. 催化剂与风险提示
- **潜在催化剂**：最新新闻公告、行业政策利好、业绩预增或新业务突破；
- **主要风险点**：行业景气度下滑、原材料成本上升、宏观及政策监管风险。

## 5. 综合评级与投资策略建议
- 给出清晰明确的研判观点（强烈看多 / 偏多积极 / 震荡蓄势 / 谨慎防守）；
- 针对短线波段交易与中长线价值持有分别提供具体的操作建议与止盈止损策略。
